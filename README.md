# 趨勢小幫手 — 股票趨勢觀測 App

告訴你 NVDA / GOOG / LLY「現在處於什麼趨勢」的觀測工具,為投資新手設計。
**描述現況、不預測漲跌、不給買賣建議**——看懂之後,決定由你自己做。

## 快速開始

- **看 App**:雙擊 `app/index.html`
- **更新資料(本機)**:雙擊 `run_daily.bat`,約 30 秒
- **雲端全自動 + 手機使用(推薦)**:照 `docs/GITHUB_SETUP.md` 一步步設定 GitHub,
  之後每個交易日早上 6 點自動更新,手機打開網址就是最新

## App 內容

| 區塊 | 說明 |
|---|---|
| 趨勢判定 | 上升趨勢 / 下降趨勢 / 盤整,技術分析標準定義(均線排列 + ADX),附專業說明 |
| 財報倒數 | 距下次財報天數(財報前後波動加大,事先提醒) |
| 支撐 / 壓力位 | 近 60 日最低 / 最高價,判斷區間與停損參考 |
| 技術指標面板 | 均線排列、相對大盤強弱(RS)、RSI、MACD、布林通道 %B、ADX、年化波動率 |
| 走勢圖 | 股價 + S&P 500 對照(等比例)+ 成交量 + 重大波動日標記 |
| 基本面卡片 | 市值、本益比、預估本益比、EPS / 營收年增率、股息殖利率 |
| 新聞 | 最新 8 則,含原文摘要 |
| 學習頁 | 所有術語白話解釋 + 新手 FAQ |

## 專案結構

```
├── app/                  App 本體(index.html + data.js)
├── pipeline/             四支資料程式(股價 / 事件新聞 / 基本面 / 組資料)
├── data/                 raw(股價 CSV)與 processed(JSON)
├── run_daily.py / .bat   一鍵更新
├── docs/                 ARCHITECTURE.md(架構)、GITHUB_SETUP.md(雲端部署教學)
└── .github/workflows/    GitHub Actions 每日自動更新
```

## 修改追蹤清單

在 `pipeline/` 四支程式的 `WATCHLIST`(以及 `build_app_data.py` 的 `INFO`)加上代號即可。

## 免責聲明

本工具僅供個人研究參考,描述歷史與現況,不構成投資建議。
資料來源 Yahoo Finance,非即時報價。投資有風險,過去走勢不代表未來。
